Chroma-key MP4

—

The mouth over a solid key colour at your frame rate, with the voice track muxed in. Drop it on a timeline and key the background out.

Video chroma is half-resolution, so the key edge is softer than the PNG alpha. For a clean matte, use the frame sequence. With the puppet behind it the frame becomes the whole picture at the puppet's own proportions, and a cut-out puppet's transparency fills with the key colour — so keying it out cuts it out again on the far side.

Final Cut Pro project

—

The puppet has been moved on the stage, and it is a video. Final Cut gets the clip as it is — place it there to match.

Batch Export gives you one project holding every clip on one timeline in load order, each as its own compound clip — not a project apiece. For one clip's own project, switch to Current Selection Export.

An .fcpxml project plus full-frame transparent PNGs, one clip per run of frames. File > Import > XML in Final Cut, then paste the clips over your footage — no transform needed, the placement is already baked in. Keyframes and the blur patch stay out of it; those belong to the overlay video.

Wrapped, the run of mouth clips arrives as one item you can slide, trim and stack in one go; open it to get at the individual shapes. Untick to drop the bare clips straight onto the spine. Leave the folder empty and the project points at the PNGs beside it, so the unzipped folder just works. Fill it in with where the folder will end up and the paths become absolute. Either way, if Final Cut shows the clips as missing, File > Relink Files reconnects them all at once. Include the other layers ships the puppet itself in the zip and puts it on the storyline with the mouths connected above — a layer you can still move, not pixels baked together. Include the voice track puts the audio in the project too, connected below the mouths at 00:00, so there is nothing left to drag in.

The whole scene

—

—

Every clip in the queue, end to end, in one file — each line wearing whoever was cast on it. The zip holds the picture, the joined voice track and a note listing the lines with their timings.

The clips are butted together rather than placed at their original offsets. A split cuts on the middle of a pause, so half of each pause ends one line and half begins the next; end to end reproduces the original timing, and anything dropped stays dropped.

The frame is taken from the first line. Placements are fractions of the frame and a puppet keeps its own shape, so a line with a differently proportioned character sits in the middle of the frame rather than being stretched — set a canvas if you want a particular size for the whole scene.

The animated PNG is the one to use: a real alpha channel, every colour, one walk through the queue. The GIF has to count a palette across the whole scene before it can index any of it, so it walks the queue twice and takes about double the time.

Transparent GIF

—

The mouth on its own, animated, with a see-through background. Drops onto a slide, a web page or a chat window without a matte.

GIF transparency is one colour, not an alpha channel, so the soft edge of the mouth becomes a hard one and the picture is cut to 255 colours. For a clean edge over video, use the animated PNG, the frame sequence or the Final Cut project. With Include the other layers ticked every frame is the whole picture, so the long edge is held to 800px however big an output size is chosen — a GIF stores each frame whole and a full-size one is unusable.

Animated PNG

—

The same animation as the GIF in a single file, but with a real alpha channel and every colour. One .png that plays.

Soft edges survive, so it sits over video without a matte and without the GIF's staircase. Bigger than a GIF — every frame carries its own pixels. Anything that does not animate APNG shows the first frame instead of failing.

Chart + exposure sheet

—

One PNG per shape, plus frame-by-frame timing as JSON and CSV. The small, sane option for After Effects, Blender or Spine.

Sprite sheet + atlas

—

Every shape packed into one PNG with a coordinate map, for game engines and web animation.

With the puppet behind it the cells become whole pictures: nine of them for a still puppet that is not being moved, and one per frame for a video or a keyframed move, with an added sequence list in the atlas saying which cell each frame wants. The sheet is held to 4096px either way.

PNG frame sequence

—

One transparent PNG for every frame, numbered. Drops straight onto a timeline — and gets big fast.

With Include the other layers ticked every frame is the whole picture at the puppet's own size, transparency and all; untick it for the mouth on its own.
